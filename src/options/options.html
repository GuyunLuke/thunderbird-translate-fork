Thunderbird Translate Fork Settings

If you don't have a Gemini key yet, you can get one for free at https://aistudio.google.com/apikey.

Privacy notice: When you request a translation we send only the email message body (the HTML source or, if not available, the plain-text body) to the translation provider you configured (Google's Generative Language API by default, or any OpenAI-compatible endpoint you specify) to produce the translation. We do not send your account credentials, mailbox headers, recipients, subject, attachments, or other mailbox metadata. The API key you enter is stored locally in the add‑on (browser.storage.local) and is used solely to authenticate requests to the configured provider. HTML markup is included so structure can be preserved; URLs and email addresses are part of the sent content but are instructed not to be altered. Do not translate sensitive or confidential content if you require full privacy.
